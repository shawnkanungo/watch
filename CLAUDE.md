## Catalog data

The video catalog is a **static, build-time snapshot**: `content/videos.json`.

- Generated by `scripts/fetch-youtube-catalog.mjs` via `npm run fetch:videos`,
  which runs automatically as `prebuild` before `npm run build`.
- Do not call the YouTube Data API at request/render time — the site only
  ever reads `content/videos.json`.
- Re-running `npm run fetch:videos` is idempotent: same channels in, same
  100 (or fewer) records out, sorted newest → oldest.
- Requires `YOUTUBE_API_KEY` in `.env.local` (gitignored).
